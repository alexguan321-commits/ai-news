  • ⭐ 涨价策略开端（结束长期"品质提升价格不变"策略）

    • 二、做对了什么（成功经验）

    2.1 LifeWear：全球统一的品牌身份

    核心理念：

    "Made for All"——为所有人设计的高品质、功能性日常服装

    关键要素：

  • 与东丽(Toray)近20年深度合作：HEATTECH、AIRism、DRY-EX、Ultra Light Down
  • 超过10,000次原型测试诞生HEATTECH
  • "Simple Made Better"——不追逐潮流，而是进化和完善基础款

    • 为什么有效：

  • 全球统一身份：无论在东京、纽约还是上海，品牌身份一致
  • 功能性壁垒：面料科技是竞争对手难以复制的
  • 跨文化普适性：基础款不受文化差异影响

    • 2.2 有明项目：数字化不是独立项目，是经营系统

    核心：从"制造零售商"→"数字消费零售业"

    关键能力：

  • RFID全门店部署（2017年起）
  • "天气预报式"供应链：实时追踪销售调整生产
  • AI需求预测→每周调整生产计划
  • FY2025成果：季末滞销库存减少~15%

    • 为什么有效：

  • 数字化不是"IT部门的事"，是整个经营系统的升级
  • RFID是一切的基础：自助结账、全渠道库存、供应链可视化
  • AI驱动精准运营：减少过剩库存+提升售罄率

    • 2.3 全球化真正落地

    数据：

  • 海外收入占比：从~45% → >55%
  • 北美FY2025：+24.5%
  • 欧洲FY2025：+33.6%
  • 东南亚FY2025：+14.6%

    • 为什么有效：

  • 不依赖单一市场（中国从"增长引擎"变为"结构调整区"时，欧美补位）
  • LifeWear全球普适（基础款不受文化差异影响）
  • 旗舰店策略（芝加哥、纽约、罗马等全球核心商圈）

    • 2.4 供应链透明度行业领先

    关键里程碑：

  • FY2023：所有产品可追溯至原材料级别
  • 与东丽深度合作（面料科技壁垒）
  • 工匠(Takumi)制度：熟练工匠每周巡视工厂

    • 为什么有效：

  • 消费者信任（透明度=信任）
  • 品质管控（从原材料到成品的全链控制）
  • ESG合规（满足投资者和监管要求）

    • 2.5 可持续发展提前达标

    关键成果：

  • Scope 1&2减排90%目标提前4年达成
  • RE.UNIQLO STUDIO：修补+改造+回收
  • CDP气候变化A List连续入选

    • 三、做错了什么（失败教训）

    3.1 中国市场：从"3000家目标"到净闭店

    问题：

  • 2020年目标3000家 → 2022年修正为"3000家是最低目标" → 现实：从峰值925降至881家
  • 三线城市关店率高达10%
  • FY2025大中华区营收-4.0%，利润-12.5%（全球唯一负增长）

    • 原因：

  • 过度扩张后遗症：约150家门店无法吸引客流
  • 涨价+品质不升：消费者反映"款式不变，价格越来越高"
  • 本土竞争：UR、蕉内、MUSINSA Standard等蚕食份额
  • 本土化不足：CFO承认"未编制足够的产品组合满足各地需求"

    • 教训：

    门店数量不等于品牌力。3000家目标暴露了"规模崇拜"思维。

    3.2 继任计划：20年找不到接班人

    时间线：

  • 2002年：玉塚元一被任命为CEO → 2005年因业绩下滑辞职，柳井正重新出任
  • 2023年：塚越大介接任Uniqlo社长
  • 2025年：柳井正（76岁）仍担任集团CEO

    • 核心问题：

  • 两次交棒均不彻底
  • 两个儿子在董事会，但柳井正明确表示"不会把公司交给他们"
  • Puck News评论："柳井正 supposed to retire years ago, but the 77-year-old is still vetoing sweaters"

    • 教训：

    创始人无法放手=组织无法成熟。继任不是找一个人，是建一个制度。

    3.3 新疆棉表态：地缘政治的代价

    事件：

  • 2024年11月：柳井正BBC采访首次公开表态"不使用新疆棉"
  • 后果：股价大跌（9周最大跌幅）+中国消费者抵制风险
  • 中国外交部回应

    • 教训：

    供应链声明需极度审慎。在全球化时代，每一个表态都有代价。

    3.4 "消费者心态变了"：永远不要指责消费者

    事件：

  • 2024年7月：大中华区CEO潘宁将业绩下滑归因于"中国消费者心态变化"
  • "优衣库高管称中国消费者心态变了"登上微博热搜
  • 消费者反感：将自身产品力不足归咎于消费者"变心"

    • 教训：

    永远不要指责消费者。业绩下滑时，先反思自己，不是怪市场。

    3.5 GU品牌中国二次创业失败

    问题：

  • 2017年进入中国，2023年提出"未来3-5年开50家店"
  • 截至2025年8月：内地仅剩深圳2家门店
  • 上海淮海中路中国首店（2017年开设）于2025年8月关闭

    • 教训：

    姐妹品牌不等于主品牌延伸。GU在中国没有找到自己的定位。

    3.6 环保争议：评级D-

    问题：

  • Stand.earth评分D-："在逐步淘汰化石燃料基面料方面行动缓慢"
  • Earth.Org将优衣库列入"5大漂绿快时尚品牌"
  • 环境目标未经科学批准（SBTi未认证）

    • 教训：

    ESG不是营销，需要可验证行动。即使Scope 1&2提前达标，供应链（Scope 3）仍是短板。

    四、核心经营理念

  • "一胜九败"：视商业为一系列科学实验，从失败中学习
  • "改变服装，改变常识，改变世界"：企业使命
  • "上帝在细节中"：极致执行基本功
  • "服装民主化"：全世界每个人都有权利穿上精心设计、用高品质材料精心制作的服装

    5.1 可以学的
    


    

    优衣库做对的UR可以学的具体做法
    

    LifeWear全球统一身份定义清晰的品牌语法"快奢"需要全球统一的身份表达
    

    有明项目（数字化经营系统）数字化不是IT项目，是经营系统RFID+AI+CDP整合为统一平台

    供应链透明度（原材料级追溯）主动供应链透明化透明度=信任
    

    独立门店管理赋权门店从"连锁管理"到"单店经营"

    涨价+品质不升涨价必须匹配品质提升消费者会流失
    

    "消费者心态变了"永远不要指责消费者先反思自己
    

    继任20年未解决需要制度化交接创始人无法放手=组织无法成熟
    

    GU中国失败姐妹品牌需要独立定位不能简单复制主品牌

    七、一句话总结
    


    优衣库用5年证明了：LifeWear全球统一身份+数字化经营系统（有明项目）+面料科技壁垒=营收+60%、利润+127%。但也证明了：3000家目标是规模崇拜、涨价不匹配品质会失去消费者、创始人无法放手是组织最大瓶颈、地缘政治表态代价极高。
