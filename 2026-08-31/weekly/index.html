对 FDE 的关键信号： AgentOps ≠ MLOps（Towards Data Science 深度文章）、8 Tips for Writing Effective Agent Instructions、FAQ as RAG——FDE 的核心技能正在从「构建 agent」转向「运营 agent」。

🏆 本周 Top 10 事件

1. 🔴 Anthropic 发布 Model Hardware Standard——让 AI Agent 操作物理机器

事件： Anthropic 发布 Model Hardware Standard，这是一个帮助 AI agent 操作物理机器的标准接口。这是 Anthropic 持续推动 Physical AI 的最新举措。

判断： 这是 Anthropic 战略方向的重要信号。当其他人还在讨论 LLM 的下一个 benchmark 时，Anthropic 已经在构建「LLM 如何控制物理世界」的标准。这意味着 Anthropic 认为 agent 的终极价值不在于生成文本，而在于操控物理世界。

更深层的信号：Anthropic 在 MCP（软件工具协议）之后推出 Model Hardware Standard（硬件控制协议），说明它正在构建一个从「数字 agent」到「物理 agent」的完整栈。

启示： FDE 团队需要关注 Physical AI 的技能需求——当 agent 不仅操作软件还操作硬件时，FDE 的知识范围需要从「API 集成」扩展到「传感器-执行器集成」。

可验证预测：12 周内，至少 2 家机器人公司会宣布支持 Model Hardware Standard。

2. 🔴 Sony Music + Warner 起诉 Anthropic「大规模知识产权盗窃」

事件： Sony Music Publishing 和 Warner Chappell 在加州北区联邦法院起诉 Anthropic，指控其侵犯「数万首」版权作品。这是针对 AI 训练数据版权的最大规模诉讼之一。

判断： 这场诉讼的意义超越了 Anthropic 本身。它正在测试一个根本性问题：AI 训练是否构成版权侵权？ 如果原告胜诉，所有使用版权数据训练模型的公司都将面临法律风险。

同周还有「音乐人变侦探追捕 AI 骗子」的报道——说明 AI 生成内容的版权和真实性问题正在从理论走向实践。

启示： FDE 团队在企业 AI 部署中需要考虑：(1) 训练数据的版权合规；(2) 生成内容的知识产权归属；(3) 建立 AI 输出的版权审计流程。

3. 🔴 ChatGPT 在欧盟面临更严格的 DSA 监管

事件： The Verge 报道，OpenAI 将很快需要为 ChatGPT 在欧盟的影响承担更多责任——包括对未成年人的影响、用户心理健康、非法内容传播。ChatGPT 将被认定为需要承担更高义务的 DSA 平台。

判断： 这是「AI 监管从软到硬」的标志性事件。欧盟不再把 ChatGPT 当作「技术实验」对待，而是当作「媒体平台」监管。这意味着： 1. 内容审核义务：OpenAI 需要主动审核和删除非法内容 2. 未成年人保护：需要实施年龄验证和内容过滤 3. 透明度要求：需要公开算法决策的逻辑

同周 NY 州长 Hochul 公开呼吁 AI 应该「less evil」——美国州级层面的 AI 监管也在加速。

启示： FDE 团队在企业 AI 部署中需要关注合规要求——特别是跨国企业需要满足不同司法管辖区的监管要求。

4. 🔴 OpenAI：ChatGPT Ads 年化收入 $10 亿 + 停止向 Cursor 提供模型

事件：

  • ChatGPT Ads 年化收入达到 $10 亿并全球扩展——AI 行业首个广告支撑商业模式验证
  • OpenAI 宣布停止向 Cursor 提供模型——因为 Cursor 被 SpaceX 收购

判断： 这两件事合在一起揭示了 OpenAI 的战略转型：

ChatGPT Ads 的意义： 这是 AI 行业的「Google 时刻」——当 AI 对话界面成为用户获取信息的主要入口，广告自然会跟着来。$10 亿年化收入说明广告主认可 AI 对话界面的价值。但这也带来了新的风险：当 AI 的回答受到广告影响时，用户的信任会被侵蚀。

停止向 Cursor 提供模型的信号： OpenAI 正在重新评估其商业关系。Cursor 被 SpaceX 收购后，OpenAI 选择终止合作而非继续——这说明 OpenAI 对竞争对手的生态扩张持防御态度。

启示： FDE 团队需要：(1) 评估 ChatGPT Ads 对企业 AI 使用的影响——广告是否会扭曲 AI 的建议；(2) 关注 AI 供应商的商业关系变化——避免单一供应商依赖。

5. 🟠 VentureBeat：身份和权限不足以治理 AI Agent 行为

事件： VentureBeat 发表深度文章指出，身份和权限管理已经不足以保障企业 AI agent 的安全——它们只能控制 agent 能访问什么，不能控制 agent 在访问后如何行为。

判断： 这是对上周 MCP 安全危机讨论的理论升级。上周我们说「MCP 安全问题是 Agent 生态的 SSL 时刻」，本周 VentureBeat 进一步指出：即使解决了访问控制，还有行为控制的问题。

这揭示了一个根本性的架构挑战：

  • 传统安全模型：身份 → 权限 → 访问控制
  • Agent 安全模型：身份 → 权限 → 行为治理

行为治理比访问控制难得多——因为 agent 的行为是动态的、上下文相关的、难以预测的。

启示： FDE 团队需要建立 agent 行为治理框架：(1) 定义 agent 的「不可为」边界；(2) 实施 agent 行为的实时监控；(3) 建立 agent 行为的审计日志。

6. 🟠 AgentOps ≠ MLOps：当 Agent 进入生产环境时监控栈会崩溃

事件： Towards Data Science 发表深度文章指出，MLOps 的 5 个监控假设在 agent 场景下全部失效——agent 的非确定性行为让传统的 MLOps 监控方法失效。

判断： 这是对「agent 运营」这个新兴领域的重要定义。文章的核心洞察是：agent 不是模型，而是系统——它包含模型、工具、记忆、规划等多个组件，每个组件都可能失败。

传统的 MLOps 监控关注：模型准确率、推理延迟、数据漂移 Agent 运营需要监控：工具调用成功率、规划合理性、记忆一致性、行为安全性

启示： FDE 团队需要建立 AgentOps 能力——这不是 MLOps 的简单扩展，而是一个全新的运营范式。

判断： 这个数字（$10 亿）说明 Figure AI 对 Figure 03 的能力有极强的信心——它愿意投入 $10 亿来证明人形机器人可以替代人类工人。

8. 🟠 Instagram 打击 AI 假账号 + 更名标签

事件： Instagram 开始打击伪装成人类的 AI 账号，并将「AI creator」标签更名为「AI-generated profile」以更清楚地标识 AI 生成内容。

判断： 这是平台对 AI 生成内容的防御性反应。当 AI 生成的假账号「越来越难辨别」（The Verge 原文），平台被迫采取更强硬的措施。

这个趋势会扩展到更多平台——当 AI 生成内容泛滥时，平台需要建立新的内容真实性标准。

启示： FDE 团队需要关注：(1) 企业社交媒体账号的 AI 生成内容标识；(2) AI 生成内容的合规要求。

9. 🟡 FAQ as RAG：当你有机会设计语料库时

事件： Towards Data Science 发表文章探讨 FAQ as RAG 的设计模式——当你可以设计 FAQ 语料库时，标准 RAG 管道的每个环节都被反转：解析变得简单，检索同时充当缓存，few-shot prompting 成为检索策略。

判断： 这是对 RAG 实践的重要反思。标准 RAG 假设语料库是给定的、混乱的——但当你有机会设计语料库时，整个管道可以大幅简化。

启示： FDE 团队在构建企业知识库时应该：(1) 优先设计结构化的 FAQ，而非收集非结构化文档；(2) 利用 FAQ 的结构化特性简化 RAG 管道。

10. 🟡 EU 的 AI 驱动正在破坏其自身的芯片战略

事件： IEEE Spectrum 报道，欧盟在推动 AI 发展的同时，其芯片战略正在受到削弱——AI 需要的芯片和欧盟想要自产的芯片不是同一类。

判断： 这揭示了地缘政治对 AI 发展的深层矛盾：

  • 欧盟想要 AI 领先 → 需要大量先进芯片
  • 欧盟想要芯片自主 → 需要时间和投资
  • 两者在短期内是矛盾的

启示： FDE 团队在技术选型时需要考虑供应链的地缘政治风险——芯片供应的不确定性会影响 AI 基础设施的长期规划。

趋势判断： Ontology 正在从「知识表示」扩展到「行为表示」。当 agent 的治理成为焦点，ontology 需要回答的新问题包括：

  • 什么 agent 行为在什么条件下是可接受的？（行为 ontology）
  • 什么 agent 输出是可信的？（可信度 ontology）
  • 什么物理动作在什么条件下是安全的？（物理安全 ontology）

对 FDE 的建议： (1) 从 agent 行为治理开始，构建行为 ontology；(2) 评估 Model Hardware Standard 的接口 ontology；(3) 为 agent 指令建立形式化的语义规范。
