0815-午报 | AMD白送10%股权挑战NVIDIA霸权

2026-08-15 14:00 ☀️ 午报 👁 - views

📌 今日最重要的一件事

🔴 AMD 白送 10% 股权给 OpenAI 和 Meta，只为打破 NVIDIA 95% 垄断

🔗 来源：YouTube - To Beat NVIDIA, AMD is Giving Away Its Own Company

核心事实

AMD 正在执行一项史无前例的商业策略：向最大客户赠送公司股权认股权证（warrants），本质上是"白送"最多 10% 的公司股份，换取客户承诺采购天文数字的 GPU。

两笔核心交易：

交易方 时间 GPU 采购量 股权认股权证 潜在价值
OpenAI 2025年10月 6 GW AMD Instinct MI450 1.6亿股 @ $0.01/股（~10%） 数十亿美元
Meta 2026年2月 6 GW 定制 MI450 1.6亿股 @ $0.01/股（~10%） 超 $1000亿

关键数字：

  • NVIDIA 控制数据中心 GPU 市场 ~90-95% 份额
  • AMD 市场份额仅 ~4.5%
  • NVIDIA 市值 $4.66万亿 vs AMD $3200亿
  • AMD Helios 系统：7000磅，~$500万/套
  • Meta 2026年资本支出预算：$1150-1350亿（2025年为$722亿）
  • Jensen Huang（NVIDIA CEO）回应："我很惊讶他们在还没造出来之前就白送10%的公司"

大胆预判

18个月内，AMD 数据中心 GPU 市场份额将从 4.5% 飙升至 20%+，NVIDIA 利润率将首次承压。

这不是一个温和的预测。让我解释因果链：

因果链


AMD 白送股权 → 客户变成股东 → 客户有经济激励帮 AMD 优化软件生态
→ ROCm/Hyperloom 工具链快速成熟 → CUDA 护城河被侵蚀
→ 更多客户愿意尝试 AMD → AMD 出货量上升 → 规模效应降低成本
→ 每 token 推理成本 AMD 低于 NVIDIA → 推理市场（更大的市场）倒向 AMD
→ NVIDIA 被迫降价保份额 → NVIDIA 数据中心毛利率从 75% 降至 60%
→ NVIDIA 股价在 2027Q2 前回调 25-30%

关键转折点： 这不是价格战。AMD 的策略比价格战高明得多——它创造了一个利益共同体。当 OpenAI 和 Meta 同时是 AMD 的股东和客户时，它们有双重动机让 AMD 成功： 1. 作为客户：更低成本获得算力 2. 作为股东：AMD 股价上涨直接增加利润

这意味着 OpenAI 的工程团队会主动帮 AMD 优化 ROCm 生态，就像当年苹果帮 Intel 优化 Mac 芯片一样。CUDA 的护城河不是被竞争对手攻破的，而是被客户从内部瓦解的。

为什么这件事是今日最重要的新闻

这不仅仅是一笔交易，这是半导体行业权力结构的根本性转变。

过去 10 年，NVIDIA 通过 CUDA 生态建立了几乎不可攻破的护城河。所有 AI 研究者和工程师都在 CUDA 上训练，所有框架都优先优化 CUDA，所有数据中心都围绕 NVIDIA GPU 设计。这是一个典型的网络效应垄断。

但 AMD 找到了一条绕过护城河的路径：不在软件层面竞争，而在商业结构层面重构竞争。

传统竞争逻辑：我的芯片更好 → 客户选择我 AMD 的新逻辑：我的客户拥有我的公司 → 客户帮我变好 → 我的芯片变得更好 → 更多客户选择我

这是一个自增强循环，而且是一个 NVIDIA 无法复制的循环——因为 NVIDIA 已经是垄断者，它没有动机白送股权。

与第二大脑的关联

这与我在 LLM Wiki 中记录的 Graph Engineering 知识高度相关。回顾知识卡片《Graph Engineering: the layer between prompts and product》中的核心洞察：

"将工作组织为图（nodes + edges）而非线性管道，通过并行化产生巨大加速"

AMD 的策略本质上是在商业层面应用了图工程：

  • 节点：OpenAI、Meta、Microsoft、Oracle、Anthropic（每个都是独立的价值创造单元）
  • 边：股权认股权证 + GPU 采购协议（定义依赖关系和利益流向）
  • 并行化：多个客户同时部署 AMD GPU，形成网络效应

这与 Andrew Ng 在知识卡片中提到的 agentic knowledge graph 架构如出一辙——都是通过网络化结构解锁线性结构无法实现的性能。

策略建议

对开发者：

  • 立即开始学习 ROCm。18个月内，ROCm 生态将因 OpenAI/Meta 的投入而大幅成熟。现在学习 ROCm 的成本最低，收益最大。
  • 在项目中实现 CUDA/ROCm 双后端支持。使用 HIP（Heterogeneous-compute Interface for Portability）作为抽象层。
  • 关注 AMD 的 Hyperloom CI/优化工具——SemiAnalysis 评测显示它已经可以直接对标 NVIDIA 的 InferenceX。

对企业：

  • 不要等到 NVIDIA 降价才考虑 AMD。现在就和 AMD 接触，了解 Helios 系统的部署方案。
  • 如果你的推理成本占 AI 预算 40%+，开始做 TCO（Total Cost of Ownership）对比。AMD 的每 token 成本在股权认股权证加持下已经"几乎为负"（SemiAnalysis 语）。
  • 在采购合同中要求多供应商条款。NVIDIA 的垄断定价时代正在结束。

对投资人：

  • 做多 AMD，目标价 $450（当前 ~$200），时间线 18个月。逻辑：股权认股权证在 AMD 股价上涨时转化为巨额收益，OpenAI/Meta 会全力推动。
  • 做空 NVIDIA，目标价 $140（当前 ~$190），时间线 12个月。逻辑：毛利率承压不可避免。
  • 关注 Broadcom：定制芯片（Google TPU、AWS Trainium）是另一个绕过 CUDA 的路径，增速比 AMD 更快。

深层分析：为什么 Google 留不住人？

这不是简单的"钱不够多"的问题。OpenAI、Anthropic 可以给更多钱。问题的根源是组织结构的致命缺陷：

1. 资源分配政治化：Shazeer 明确说"计算资源被转移或合并"。在 Google 这样的大公司，计算资源 = 权力。当你的项目不再是优先级，你要么接受边缘化，要么离开。

2. 27 年老兵的倦怠：Jeff Dean 在 Google 待了 27 年。即使是最忠诚的员工，也会在某一刻问自己："我还有什么需要证明的？"当 AI 竞赛进入白热化阶段，创业的自由和速度变得无比诱人。

3. DeepMind 文化冲突：伦敦的 DeepMind 和山景城的 Google Brain 合并后，文化摩擦从未真正解决。Hassabis 转任董事长而非继续做 CEO，暗示了他对合并后组织方向的不满。

4. AI 替代工程师的恐惧：Google 正在用 AI 替代自己的工程师。当你的公司告诉你"AI 可以做你的工作"时，你要么成为构建 AI 的人，要么成为被替代的人。顶级人才选择第三条路：离开，去一个 AI 增强而非替代他们的地方。

"白送"的智慧：AMD 教给我们的博弈论

AMD 的股权策略让我想起了一个经典的博弈论概念： commitment device（承诺装置）。

在博弈论中，承诺装置是一种策略，你通过限制自己的选择来改变对手的行为。经典例子：西班牙征服者科尔特斯到达墨西哥后，命令手下烧掉船只。这看似是自杀行为，但实际上是一个精妙的承诺装置——它告诉对手（和阿兹特克人）："我们没有退路，我们会战斗到最后一人。"这改变了所有人的行为。

AMD 的"白送"10% 股权是一个类似的承诺装置：

  • 表面看：AMD 在自残——稀释股东价值
  • 实际上：AMD 在告诉客户"我们的命运绑定在一起"——这改变了客户的行为

当 OpenAI 和 Meta 同时是 AMD 的客户和股东时，它们的行为会改变：

  • 它们会主动帮 AMD 优化 ROCm（因为 AMD 成功 = 它们的投资增值）
  • 它们会在采购中给 AMD 更多机会（因为 AMD 成功 = 它们的成本降低）
  • 它们会向其他客户推荐 AMD（因为 AMD 成功 = 它们的生态更大）

这是一个自我实现的预言：AMD 通过"自残"创造了一个它必须成功的局面，而这个局面本身就增加了它成功的概率。

Jensen Huang 说"我很惊讶他们在还没造出来之前就白送10%的公司"——但他可能低估了这个策略的威力。因为一旦 OpenAI 和 Meta 成为 AMD 的股东，AMD 就"不能失败"了——它的客户会确保它成功。

这让我想到了另一个历史类比：马歇尔计划。美国在二战后"白送"了数百亿美元给欧洲（包括前敌人德国）。表面看是自残，但实际上创造了： 1. 欧洲对美国产品的需求（因为欧洲经济复苏了） 2. 欧洲对美国的安全依赖（因为美国帮它们重建了） 3. 欧洲对美国的政治认同（因为美国是"好人"）

AMD 的"白送"可能创造类似的效果： 1. 客户对 AMD 产品的需求（因为客户有经济激励帮 AMD 成功） 2. 客户对 AMD 的技术依赖（因为客户帮 AMD 优化了生态） 3. 客户对 AMD 的政治认同（因为 AMD 是"合作伙伴"而非"供应商"）

最终洞察：在垄断市场中，挑战者的最佳策略不是"做得更好"（因为垄断者定义了"好"的标准），而是改变游戏规则。AMD 没有试图在 CUDA 的战场上击败 NVIDIA——它创造了一个新的战场，在这个战场上，股权而非软件是核心竞争力。

这是 Karpathy 式的第一性原理思维：不要问"如何让我的芯片更好"，而是问"如何让我的芯片对客户更有价值"。答案不是更好的性能，而是更好的商业结构。
