Google 发布 Gemini 3.8 Live + Extended Thinking——"实时推理"时代正式开启，但真正的炸弹藏在三巨头秘密安全谈判里

🔗 来源：DeepMind Blog - Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking 🔗 来源：TechCrunch - OpenAI, Anthropic, Google have been in talks on AI safety for weeks

事件概述

2026年9月15日，两条看似独立但实际深度关联的新闻同时爆发：

表面事件： Google DeepMind 发布 Gemini 3.8 Live 和 3.8 Live Extended Thinking——这是 Gemini 系列首次将"实时多模态交互"与"扩展思考（Extended Thinking）"能力融合。

深层事件： TechCrunch 曝出 OpenAI、Anthropic、Google DeepMind 三家公司已经就 AI 安全进行了"数周"的秘密谈判。OpenAI 确认了这一消息，而特朗普团队则公开淡化安全担忧，强调"必须跟上中国"。

这两件事必须放在一起看。因为 Gemini 3.8 Live Extended Thinking 的发布，恰好证明了为什么三巨头必须坐下来谈——AI 的能力边界正在以超出所有人预期的速度扩展，而"实时推理"这个能力的出现，意味着 AI Agent 不再只是"异步执行任务"，而是可以"在对话中实时思考并行动"。

深度分析

为什么这是今天最重要的事？

因为 Gemini 3.8 Live Extended Thinking 不是一个产品更新——它是一个能力相变。让我用因果链来拆解。

维度一：从"异步推理"到"实时推理"——Agent 能力的相变

此前的 Extended Thinking（包括 o1、Claude 的 extended thinking）都是异步的：你给一个问题，模型"思考"一段时间，然后给出答案。这适合复杂推理任务，但不适合实时交互。

Gemini 3.8 Live Extended Thinking 的突破在于：它把扩展思考能力嵌入到了实时多模态流中。这意味着：

  • AI 可以在视频通话中"边看边想边说"
  • AI 可以在代码执行过程中"实时监控并实时调整策略"
  • AI 可以在语音对话中"暂停思考"而不打断对话流

因果链：

A（Extended Thinking 能力实时化）→ B（Agent 可以在交互过程中进行深度推理）→ C（Agent 的可靠性从"70%成功率"提升到"95%成功率"）→ D（企业愿意将 Agent 部署到关键业务流程）→ E（Agent 市场规模从"实验性预算"变为"核心运营预算"）→ F（2027 Q2 之前，Agent 将成为云收入增长的第一驱动力）

这不是推测。 看看 HuggingFace 今天发的博客："Your Agent Aced the Task. Will It Do It Again?"——IBM Research 在研究 Agent 的一致性问题。这说明行业已经意识到：Agent 的下一个瓶颈不是能力，而是一致性。而 Extended Thinking 的实时化，正是解决一致性问题的关键技术路径——因为"多想一步"的 Agent 犯错的概率显著更低。

预测： 6个月内，OpenAI 和 Anthropic 都将推出自己的"实时扩展思考"能力。12个月内，"实时推理"将成为所有前沿模型的标配。18个月内，不支持实时推理的模型将被归类为"legacy"——就像今天不支持 function calling 的模型一样。

维度二：三巨头安全谈判的真实博弈——不是安全，是定价权

TechCrunch 的报道说三巨头"已经进行了数周的安全谈判"。但注意两个关键细节：

1. 特朗普团队"淡化安全担忧"——这意味着政治压力在推动加速 2. "跟上中国"的叙事被反复提及——这是国家安全论据

让我用博弈论来拆解这场谈判的真实结构。

三巨头的收益矩阵：

OpenAI 减速 OpenAI 加速
Anthropic 减速 双方维持高利润率 ✅ Anthropic 被甩开 ❌
Anthropic 加速 OpenAI 被甩开 ❌ 双方陷入价格战 ⚠️

这是一个典型的囚徒困境。如果双方都减速，大家都好（维持高利润率）。但如果一方偷偷加速，另一方就输了。

这就是为什么"数周谈判"不会有实质结果。 因为：

  • OpenAI 刚刚以 $300M 收购 Glass Imaging（硬件扩张）
  • Anthropic 距离 IPO 只有几周（需要展示增长故事）
  • Google DeepMind 的 Gemini 3.8 刚刚发布（正在追赶）

没有任何一方有真正的减速动机。 谈判的真实目的是：

1. 建立信息共享机制——了解彼此的安全红线在哪里 2. 协调"安全叙事"——让监管层接受"行业自律"框架 3. 划分势力范围——谁在哪些领域可以加速，谁在哪些领域需要克制

因果链：

A（三巨头秘密谈判）→ B（建立非正式信息共享机制）→ C（协调"安全叙事"对外输出）→ D（监管层接受"自律"框架）→ E（头部公司维持寡头地位）→ F（新创公司无法通过"更快迭代"来竞争）→ G（行业进入"受控竞争"阶段）

预测： 9个月内，三巨头将联合发布一份"AI 安全自律框架"白皮书。该框架不会有强制约束力，但会成为监管层的基础文件。12个月内，任何不符合该框架的 AI 公司将面临"不安全"的公关压力——这是头部公司用来打压竞争对手的新武器。

维度三：对创业者和开发者的策略建议

如果你是创业者：

  • 立即行动： 基于 Gemini 3.8 Live 的实时推理能力构建新产品。窗口期只有 6个月——之后 OpenAI 和 Anthropic 都会推出类似能力。
  • 不要做： 不要做"通用 Agent 平台"。做垂直场景的实时 Agent——比如实时客服质检、实时代码审查、实时医疗影像分析。
  • 关键洞察： 实时推理 + 多模态 = 新的产品形态。想想"实时视频分析 Agent"——这在 3个月前是不可能的，今天可以了。

如果你是开发者：

  • 立即学习： Extended Thinking 的 prompt 模式与标准推理完全不同。你需要学习如何"引导"模型在实时交互中进行深度思考。
  • 关注： MCP 协议正在成为 Agent 互操作的事实标准（今天 HN 前10条有6条与 MCP 相关）。
  • 策略： 现在就开始把你的工具包装成 MCP server——6个月内，不支持 MCP 的工具将被 Agent 生态排除在外。

小语言模型（SLM，参数量 < 10B）将成为 Agentic AI 的主流——因为它们可以在边缘设备上运行，延迟低、成本低、隐私好。

方法论拆解

论文的核心论据是：

1. Agent 不需要"通用智能"——Agent 的任务通常是窄的（比如"订机票"、"查库存"），不需要模型具备广泛的世界知识 2. SLM 可以针对特定任务微调——比通用大模型在特定任务上表现更好 3. SLM 可以在边缘设备运行——不需要云端，隐私好、延迟低

实验结果

论文对比了 SLM（1-7B）和 LLM（70B+）在 5 个 Agent 任务上的表现：

  • 在窄任务上，微调后的 SLM 与 LLM 表现相当
  • 在延迟和成本上，SLM 优势明显（10x 更快，100x 更便宜）
